# tools

## merge_trim_video.py

細切れに録画された動画を1本に結合し、動きのない区間を自動でカットするコマンドラインツール。

必要なもの: `ffmpeg` / `ffprobe`（`brew install ffmpeg`）と Python 3.8+。
外部ライブラリは不要（numpy があれば解析が速くなります）。

```bash
# まず解析結果だけ確認（書き出さない）
python3 tools/merge_trim_video.py "/Volumes/NO NAME/record/2026/08/30" --dry-run

# 実際に書き出す
python3 tools/merge_trim_video.py "/Volumes/NO NAME/record/2026/08/30" -o ~/Desktop/merged.mp4
```

### 仕組み

1. フォルダ内の動画をファイル名順（`--sort time` で更新日時順）に並べる
2. 各動画を 64px 幅のグレースケールに縮小し、毎秒4サンプルで
   **「何 % のセルが変化したか」** を測る
3. その分布から静止と動きの境目を自動推定し、動きのある区間だけを残す
   （前後に余白を付け、短い静止は繋いだまま残す）
4. 残す区間を同じ解像度・fps に揃えて書き出し、1本に結合する

画面全体の平均変化量ではなくセル単位の変化数を数えているため、広い画角の中を
人や車が横切るような、被写体が画面の 1% 程度しか占めない映像でも検出できる。

しきい値は静止側の代表値（p10）と動き側の代表値（p90）から決める:

- 静止側がほぼ 0% → 静止区間がある。両者の間をしきい値にする
- 静止側・動き側ともほぼ 0% → 全編静止。そのファイルは丸ごと除外する
- 最も静かな瞬間にも動きがある → 全編動き。全部残す（迷ったら残す側に倒す）

### 主なオプション

| オプション | 既定値 | 説明 |
| --- | --- | --- |
| `-o, --output` | `merged.mp4` | 出力ファイル |
| `--dry-run` | | 解析結果だけ表示して書き出さない |
| `--analyze` | | 変化量の分布を表示する（しきい値の調整用） |
| `--threshold` | `auto` | 動き判定のしきい値（変化セルの%）。大きいほど多くカット |
| `--pad` | `0.7` | 動きの前後に残す秒数 |
| `--merge-gap` | `1.5` | この秒数以下の静止は繋げて残す |
| `--min-len` | `0.5` | これより短い区間は捨てる |
| `--grid-width` | `64` | 解析用の縮小幅。小さい被写体が拾えない場合は増やす |
| `--cell-threshold` | `12` | 1セルが変化したとみなす明度差 |
| `-j, --jobs` | CPU数と4の小さい方 | 解析・書き出しの並列数 |
| `--encoder` | `auto` | `auto` は Mac ならハードウェア(videotoolbox)を試験実行してから使う |
| `--no-trim` | | カットせず結合だけする |
| `--size` / `--fps` | 最初の動画に合わせる | 出力解像度 / fps |
| `--crf` | `20` | 画質（小さいほど高画質・大きいファイル） |
| `-r, --recursive` | | サブフォルダも探す |

うまくカットされない場合は `--analyze` で分布を見て、動きのある区間の値より
少し小さい値を `--threshold` に指定してください。
